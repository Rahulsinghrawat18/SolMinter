# 🌟 SolMinter – Solana Token Creator

**SolMinter** is a decentralized web application that allows users to easily create and deploy their own SPL tokens on the Solana blockchain. Whether you're launching a project, starting a community, or just experimenting with blockchain, SolMinter makes token creation seamless and user-friendly.

🌐 **Live App**: [https://solminter-ten.vercel.app](https://solminter-ten.vercel.app)

---

## 🚀 Features

- 🪙 **Create Solana SPL Tokens** in a few simple steps
- 📈 **Top Tokens** section (Coming Soon)
- 🔍 **Solana Explorer Access** for transparency and tracking (Coming Soon)
- 💬 **Newsletter Integration** – Subscribe to stay updated
- 💻 **Sleek UI** built with Next and Tailwind CSS
- 📢 **Airdrop** - Get devnet tokens to test the application
- 💡 **Token Metadata** - Paste the contract address and get the info about token.

---

## 🧰 Tech Stack

- **Solana Web3.js**
- **React + TypeScript**
- **Tailwind CSS**
- **Formspree** – for newsletter submission
- **React Icons**
